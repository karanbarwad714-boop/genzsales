# GENZSALES ⚡ | Official E-Commerce Store for GenZ Fashion

GENZSALES is a high-converting, trendy streetwear e-commerce web application built using **React** and **Vite** with **Tailwind CSS**.

## 🚀 Key Features

1. **Category Filtering & Live Search**:
   - Filter by T-Shirts (From ₹699), Shirts (From ₹799), Jeans (From ₹999), or All Drops.
   - Live search by product name, fabric, style, or tag.
   - Price range slider & Size filter pills (S, M, L, XL, 30, 32, 34).
   - Sort by Featured, Price Low to High, Price High to Low, Top Rated.

2. **Quick View & Details Modal**:
   - Multi-image gallery.
   - Interactive Color swatches & Size selector.
   - Fabric weight specs (240 GSM cotton, 14 oz denim).
   - "Order via WhatsApp" button with pre-filled product specs.
   - Interactive Size Guide Chart (Inches).

3. **Cart & Checkout Experience**:
   - Slide-over Bag Drawer with dynamic Free Shipping progress bar (Free above ₹999).
   - Coupon system: `GENZ10` (10% OFF), `GENZ20` (20% OFF above ₹1499), `FREESHIP`.
   - Full Checkout Modal with address form, UPI, Cash on Delivery (COD), Card options.
   - Confetti celebration on order placement + WhatsApp order receipt generation.

4. **Community UGC & Reviews**:
   - Lookbook Reels ("How Gen-Z Styles It").
   - Real buyer fit checks & 4.9★ community ratings.
   - Sticky WhatsApp support pill for instant customer inquiries.
